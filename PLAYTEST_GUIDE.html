LG Duel Playtest

A quick two-player lightning-gun duel. You do not need to install or configure a server.

1Get the game

Download the game folder or ZIP sent by the host. Make sure it matches your operating system.

  1. If it is a ZIP file, right-click it and choose Extract All.
  2. Open the extracted folder.
  3. Do not move individual files out of that folder.

Important: both players must use the same playtest version. An older client will not connect.

2Start and connect

The server address for this session is:

213.66.106.51:27960

Windows

Open the game folder and double-click Play LG Duel.bat. The launcher already contains the server address.

If the host sends you a new address, open server-address.txt and replace its single line with the new address.

Linux

Right-click inside the game folder, choose Open in Terminal, then paste:

./lg_duel_client 213.66.106.51 27960

Success: the game window opens and shows that you are connected or waiting for another player.

The public address may change between sessions. Use the newest address sent by the host if it differs from the one above.

3Start the match

  1. Wait until both players are connected.
  2. Each player presses F3 once to become ready.
  3. Wait for the countdown. Movement works during it, but firing is disabled.

Match rules

  • Keep the lightning beam on your opponent to deal continuous damage.
  • A kill wins one round.
  • Both players respawn after each round.
  • The first player to 10 rounds wins the match.

Something went wrong?

The window does not open: make sure you extracted the whole ZIP and launched the correct version for your operating system.

Windows shows a security warning: confirm the file came directly from the host. Choose More info, then Run anyway only if you trust the sender.

It stays disconnected: check that the host says the server is online, verify the latest server address, and allow the game through your firewall if prompted.

It says the server is full: the playtest supports only two total players.

It connects but the match does not begin: both players must press F3.

Still stuck: send the host a screenshot of the whole game window and describe what happened just before the problem.

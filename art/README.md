# Source art and trial assets

This folder keeps files used to build or review game assets. Runtime-ready
files belong in `assets`.

- `audio` holds licensed source recordings, generated audition sets, and old
  selected-file backups.
- `blender` holds current Blender source files.
- `exports` holds current exports from source art.
- `handoff` holds archived transfer packages and their notes.
- `previews` holds review images.
- `sky` holds sky source art and conversion inputs.

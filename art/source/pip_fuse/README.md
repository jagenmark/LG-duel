# Pip Fuse — original arena mechanic

Pip is an original stylized human built entirely from authored geometry. The
current design uses a continuous facial surface, a defined brow and jaw, compact
inset eyes, a swept hair shell, fitted work jacket, diagonal harness, and a small
shoulder pressure gauge connected to a back regulator.

No existing model, texture, rig, animation or image is loaded by the generator.
The source is procedural construction code, not a downloaded or modified asset.

## Files

- `build_character.py`: geometry helpers, rig, original clips, export and studio.
- `sculpt_character.py`: current character surface construction and materials.
- `pip_fuse.blend`: editable dense source with the original 14-joint rig and 18 authoring actions.
- `assets/models/pip_fuse/pip_fuse.glb`: reduced runtime model.
- `scripts/author_player_animations.py`: runtime ankle joints, planted-foot IK
  and expanded animation set. Studio previews are regenerated by the builder.

Run from any directory with Blender 4.5:

```sh
blender --background --python /path/to/LG-duel/art/source/pip_fuse/build_character.py
```

The generator resets the Blender scene, builds all surfaces and materials,
exports a separate runtime copy at 60% of source topology, saves the dense
editable source, and renders four studio views. Studio geometry is excluded
from the GLB. Material colors, roughness and metalness are authored PBR values;
there are no input texture assets.

## Game integration and remaining limitations

The default player loader uses this GLB. The existing `workerPlayerModel` API
name is retained for compatibility. The jacket supports team tinting, and the
rig supports upper-body aim, lean and animated weapon attachments.

The 18 original animation clips include distinct runs, strafes, lean poses and
an armed idle. Most mesh sections still use rigid skin weights and the facial
expression is static. This is not a finished AAA production character: it lacks
facial controls, production deformation topology, polished animation acting,
texture baking and LOD chains. Studio renders verify surface appearance; CPU
validation and scene tests verify the loading and presentation contracts. Live
GPU appearance and performance require in-game visual validation.

Current runtime: 78,944 triangles, 13 materials, 16 joints and 25 clips.
The builder runs `scripts/author_player_animations.py` after export; this adds
ankle joints and replaces/expands the stance, contact, directional and airborne
clips. The saved Blender source retains the original authoring rig/actions.
Python NumPy is required for the post-export authoring pass.

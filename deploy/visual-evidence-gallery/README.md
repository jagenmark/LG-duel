# LG Duel private gallery

This private Sites page keeps the project's existing captures in one place. It
reads stored images from R2 and older records from `public/evidence/manifest.json`.

The gallery is optional. Project tasks can show local images in Codex and do not
need a gallery record, an outside review, or an upload token.

Local checks:

```powershell
npm install
npm run build
npm test
```
